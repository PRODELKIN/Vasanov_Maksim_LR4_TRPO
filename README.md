# Hotel_Vasanov_ISP43

WPF-приложение для гостиницы с регистрацией, авторизацией и бронированием номеров. Разработано на C#, данные хранятся в SQL Server, работа с БД выполняется через ADO.NET.

## Визуальная демонстрация

Основные страницы приложения:

- Вход и регистрация с проверкой капчи.
- Номера - просмотр, поиск по категории и сортировка по цене.
- Бронирования - просмотр и отмена своих записей.
- Управление - редактирование и удаление бронирований администратором.

На странице «Номера» администратору доступны добавление номеров и услуг.

## Установка

1. Установите Microsoft Visual Studio со средствами разработки WPF и .NET Framework 4.7.2.
2. Откройте решение `Hotel_Vasanov_ISP43.sln`.
3. Подготовьте базу SQL Server `TRPO_Hotel`.
4. Укажите сервер и название базы в строке подключения `App.config`.
5. Соберите и запустите приложение.

## Использование

1. Просмотрите номера, воспользуйтесь поиском и сортировкой.
2. Зарегистрируйтесь или войдите, указав почту, пароль и капчу.
3. Выберите номер и даты проживания, нажмите «Забронировать».
4. Откройте «Мои бронирования» для просмотра или отмены записи.

Тестовые аккаунты:

- Администратор: `admin@hotel.ru`, пароль `admin`.
- Пользователь: `user@hotel.ru`, пароль `user123`.

При регистрации создаётся только аккаунт пользователя. Администраторы добавляются непосредственно в БД.

## Структура проекта

- `Pages` - страницы приложения и обработчики событий.
- `MainWindow.xaml` - главное окно и навигация.
- `DataAccess.cs` - SQL-запросы и работа с БД.
- `Captcha.cs` - создание и проверка капчи.
- `App.xaml` - запуск приложения и общие стили.
- `App.config` - настройки подключения к БД.

## Данные

Используется база `TRPO_Hotel` с таблицами `Users`, `Roles`, `Rooms`, `RoomCategories`, `Bookings`, `Services` и `BookingServices`.

Вводимые значения передаются в SQL-запросы через параметры.
